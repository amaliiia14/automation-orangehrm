# OrangeHRM UI Test Automation

## Deskripsi Proyek

Proyek ini merupakan latihan UI Test Automation pada aplikasi web OrangeHRM menggunakan Cypress. Pengujian difokuskan pada tiga fitur utama, yaitu **Login, Directory, dan Recruitment** untuk memvalidasi fungsionalitas aplikasi berdasarkan skenario pengujian yang telah disusun.

Automation testing dikembangkan menggunakan pendekatan Page Object Model (POM) untuk memisahkan elemen halaman dan langkah pengujian agar kode lebih terstruktur dan mudah dikelola.

## Cakupan Pengujian

Pengujian otomatis mencakup tiga fitur berikut:

- **Login:** Menguji proses login menggunakan kredensial valid dan tidak valid.
- **Directory:** Menguji fungsionalitas direktori karyawan dan informasi karyawan.
- **Recruitment:** Menguji fungsionalitas recruitment, termasuk informasi kandidat dan lowongan pekerjaan.

## Implementasi Pengujian

Dalam proyek ini, beberapa pendekatan diterapkan untuk mendukung proses automation testing, yaitu:

- Menggunakan Page Object Model (POM) untuk memisahkan interaksi halaman dari test script.
- Menggunakan fixtures untuk mengelola data pengujian.
- Menerapkan selectors untuk mengidentifikasi dan berinteraksi dengan elemen halaman.
- Menggunakan assertions untuk memvalidasi hasil pengujian berdasarkan expected result.
- Menerapkan intercept untuk memantau request jaringan selama proses pengujian.

## Tujuan Proyek

Proyek ini bertujuan untuk mempraktikkan dasar UI test automation menggunakan Cypress, mulai dari penyusunan automated test, pengelolaan data pengujian, interaksi dengan elemen halaman, hingga validasi hasil pengujian.
